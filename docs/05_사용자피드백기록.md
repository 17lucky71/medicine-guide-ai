# 사용자 테스트 및 피드백 기록

- 대상: 팀원 3명(최영진, 장보윤, 이채리). 과정 담당자의 허락을 받아 팀원 3명으로 진행하며, 기록에는 T1, T2, T3으로 표기한다.
- 한계: 팀원은 서비스를 잘 알고 있어 일반 사용자 반응과 다를 수 있다. 이 점을 발표에서 함께 설명한다.
- 방법: 배포 주소에서 샘플 약봉투/처방전 사진으로 [사진 업로드 → 결과 확인·수정 → 저장 → 새 사진으로 비교]를 직접 해 보게 하고 의견을 듣는다.
- 개인정보: 이름·연락처는 적지 않고 연령대만 적는다. 개인정보가 보이는 사진은 올리지 않는다.
