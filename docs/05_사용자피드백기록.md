# 사용자 테스트 및 피드백 기록

- 대상: 팀원 3명(최영진, 장보윤, 이채리). 과정 담당자의 허락을 받아 팀원 3명으로 진행하며, 기록에는 T1, T2, T3으로 표기한다.
- 한계: 팀원은 서비스를 잘 알고 있어 일반 사용자 반응과 다를 수 있다. 이 점을 발표에서 함께 설명한다.
- 방법: 배포 주소에서 샘플 약봉투/처방전 사진으로 [사진 업로드 → 결과 확인·수정 → 저장 → 새 사진으로 비교]를 직접 해 보고 의견을 적는다.
- 개인정보: 이름·연락처는 적지 않는다. 개인정보가 보이는 사진은 올리지 않는다.

## 질문 (T2, T3 작성용)
1. 사진을 올리고 결과가 나올 때까지 어렵지 않았나요?
2. 글자 크기와 화면 구성은 보기 편했나요?
3. 약 이름이 틀렸을 때 고치는 방법을 쉽게 찾았나요?
4. 저장된 약과 비교한 안내가 도움이 되었나요?
5. 불안하거나 이해하기 어려웠던 부분이 있었나요?

## 개선 요약

- T2, T3 피드백을 받은 뒤 이 항목을 갱신한다.
