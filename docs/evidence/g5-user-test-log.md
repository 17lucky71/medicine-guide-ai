# G5 실사용자 피드백 증거

## 판정

**G5 충족.** 팀원이 아닌 실제 앱 사용자 5명 이상이 서비스를 사용한 뒤 앱 하단의 ‘피드백 보내기’로 의견을 제출했습니다.

## 보관된 증거

- 2026-10-28 익명 피드백 응답 5건: [익명 응답 요약](google-forms-feedback-2026-10-28-anonymized.md)
- 기능 사용 문항 차트: [Google Forms 차트 캡처](google-forms-feature-use-chart.png)
- 프로젝트 담당자 확인(2026-10-30): 응답자는 팀원이 아니며 실제 앱 사용자입니다. 피드백은 앱 하단의 ‘피드백 보내기’를 통해 제출됐습니다.
- 차트에서는 5건 모두 ‘처방전·약봉투 사진 분석’을 사용했다고 답했고, ‘아직 사용해 보지 않음’은 선택되지 않았습니다.

## 증거 범위

응답 요약에는 이름·연락처·연령·응답자별 ID가 없어 개인별 테스트 과정을 재구성할 수 없습니다. 따라서 이 자료는 팀원이 아닌 실사용자 5명 이상의 서비스 사용 및 피드백 제출을 뒷받침하며, 참여자별 작업 성공 여부나 연령 분포를 주장하지 않습니다. 개인정보를 추가 수집하지 않고 익명 집계 자료를 증거로 사용합니다.
