# 회의록 - 2026.10.05 (월)

- 일시: 2026-10-05 13:00 ~ 15:00 (PBL실)

## 안건
1. 팀 과제 주제 및 핵심 기능 방향 논의
2. 필수 기술 요소 선정
3. 저장소 관리 방식 논의

## 논의 내용

### 1. 타깃 사용자
- 노인 사용자 위주
- 자녀·보호자도 앱 내용을 확인할 수 있도록 구성

### 2. OCR 기능 (멀티모달 AI)
- 처방전/약 봉투 사진을 촬영하면 자동으로 인식
- 인식 결과 확인창 표시 (약 이름, 용량(mg) 등)
- 인식이 틀렸을 경우 사용자가 직접 수정 후 확인

### 3. 핵심 기능: 약 비교 분석
- 기존에 복용 중인 약과 새로 처방받은 약을 비교
- 새로 처방받은 약의 부작용 안내
- 주의사항 버튼 제공

### 4. UI 방향
- 단순하고 직관적인 화면
- 클릭·터치를 하지 않아도 주의사항을 바로 볼 수 있도록 구성

### 5. 필수 기술 요소 (G3)
- 5개 중 2개 이상 인정 수준으로 구현 필요
- 후보: Long-term Memory(복용 이력 저장), 멀티모달 AI(OCR)

### 6. 저장소 관리
- 폴더별로 정리
- 일자별로 커밋

## 결정 사항
- 타깃: 노인 + 보호자(자녀)
- 핵심: OCR 인식 → 확인·수정 → 기존 약과 비교 분석
- 기술 요소 2개 이상 적용
- 폴더 구조 정리, 일자별 커밋 원칙
