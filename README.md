## 1. 개요

약봉투나 처방전 사진을 OCR로 인식하고,
복용 중인 약과 새 약을 비교해 부작용과 주의사항을 알려 주는 서비스입니다.

노인 사용자가 스마트폰 카메라로 약봉투를 찍으면,
AI가 약 이름과 복용법을 자동으로 읽어주고,
기존에 복용 중인 약과 함께 먹어도 되는지 안전 여부를 확인해 줍니다.
결과는 가족(보호자)과 공유할 수 있어 원격에서도 복약 관리가 가능합니다.

**참고 서비스: 아이약** (제안: 장보윤)
- 처방전·약봉투 촬영 인식, 복용 약 안전성 확인, 약 알람 및 기록 기능 제공
- **우리 서비스의 차별점**

| 항목 | 아이약 | medicine-guide-ai |
|---|---|---|
| 주요 타겟 | 일반 사용자 | 노인·고령자 중심 |
| UI 설계 | 일반 크기 | 큰 글자·단순 화면 |
| 가족 공유 | 미지원 | 보호자 공유 기능 |
| 복약 안내 | 정보 제공 | AI 자연어 설명 |

## 2. 프로젝트 배경

### 📊 왜 이 문제가 중요한가

> 우리나라 65세 이상 노인의 **89%** 가 1개 이상의 만성질환을 보유하고 있으며,
> 평균 **5.1개**의 약을 동시에 복용합니다.
> 여러 약을 함께 복용할 때 발생하는 **약물 부작용·상호작용**은
> 노인 응급실 입원의 주요 원인 중 하나입니다.
>
> 출처: 건강보험심사평가원, 노인 의약품 적정성 평가 보고서

| 통계 | 수치 |
|---|---|
| 65세 이상 만성질환 보유율 | 89% |
| 노인 1인 평균 복용 약 수 | 5.1개 |
| 약물 부작용으로 인한 노인 입원 비율 | 전체 입원의 약 10~20% |
| 복약 지시 미준수율 (노인) | 약 50% |

### 😔 실제 문제 상황

병원에서 처방받은 약봉투를 받았을 때 노인 환자가 겪는 어려움입니다.

- 📋 약 이름이 어렵고 글씨가 작아 읽기 어렵습니다
- ❓ 이미 먹고 있는 약과 함께 먹어도 되는지 알 수 없습니다
- 👨‍👩‍👧 자녀·보호자가 멀리 있어 바로 물어보기 어렵습니다
- 😓 약사에게 다시 물어보기 어렵거나 민망할 수 있습니다
- ⏰ 복약 시간을 잊거나 중복 복용하는 경우가 발생합니다

### 💡 우리의 해결 방법

팀 회의(디스코드)에서 도출한 핵심 아이디어입니다.

> 💬 **장보윤**: "약봉지를 OCR로 분석해서 받아들인 정보를 한번 확인해서 저장되게끔 하는게 좋을 것 같아요"
> 💬 **이채리**: "추가하면 좋을 것 같은 기능: 큰 글자 기능, 가족과 공유 기능"
> 💬 **이채리**: "기존에 복용 중인 약이 있으면 기초 데이터로 저장"
> 💬 **장보윤**: "타겟층이 노년층인거죠"

**핵심 가치**

```
📸 약봉투 촬영
    ↓
🤖 AI OCR 자동 인식
    ↓
💊 기존 복용 약과 안전성 비교
    ↓
📋 쉬운 말로 복약 안내
    ↓
👨‍👩‍👧 가족(보호자)과 결과 공유
```

## 6. 실행 방법

### 사전 준비
- Python 3.11 이상
- Node.js 18 이상
- OpenAI API 키
- Google Vision API 키 (또는 Tesseract 로컬 설치)

### 1) 저장소 클론

```bash
git clone https://github.com/17lucky71/medicine-guide-ai.git
cd medicine-guide-ai
```

### 2) 환경변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 열어 아래 값을 입력하세요:

```
OPENAI_API_KEY=your_openai_api_key_here
OCR_API_KEY=your_ocr_api_key_here
DATABASE_URL=sqlite:///./medicine.db
```

> ⚠️ `.env` 파일은 절대 GitHub에 올리지 마세요. `.gitignore`에 포함되어 있습니다.

### 3) 백엔드 실행

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

백엔드 서버: `http://localhost:8000`
API 문서: `http://localhost:8000/docs`

### 4) 프론트엔드 실행

```bash
cd frontend
npm install
npm run dev
```

프론트엔드: `http://localhost:5173`

## 8. 기술적 도전과제

### 🔍 OCR 정확도 문제

약봉투는 글씨가 작고 배경이 복잡해 OCR 인식률이 낮았습니다.

**문제 상황**
- 약봉투 특성상 글씨가 작고 밀집되어 있음
- 촬영 각도·조명에 따라 인식률 편차가 큼
- 약 이름에 영문·한글·숫자가 혼재

**해결 방법**
- 이미지 전처리(그레이스케일 변환, 이진화, 노이즈 제거)로 인식률 개선
- 사용자가 OCR 인식 결과를 직접 수정할 수 있는 편집 UI 추가
- Tesseract와 Google Vision API를 비교 테스트 후 상황별 선택 적용

---

### 💊 약물 정보 매칭 문제

OCR로 인식한 약 이름이 DB의 약 이름과 정확히 일치하지 않는 경우가 많았습니다.

**문제 상황**
- OCR 오인식으로 약 이름 일부가 틀리게 인식됨
- 동일 약의 제품명·성분명·약어가 혼용됨
- 완전 일치 검색 시 검색 실패율이 높음

**해결 방법**
- 유사도 기반 검색(퍼지 매칭, difflib)을 도입해 오인식된 약 이름도 검색 가능하도록 개선
- 약 제품명·성분명·약어를 모두 포함한 통합 검색 인덱스 구성
- 매칭 신뢰도가 낮을 경우 사용자에게 후보 목록을 제시해 직접 선택하도록 UX 설계

---

### 👴 노인 친화적 UI 설계

일반적인 UI는 노인 사용자에게 복잡하게 느껴질 수 있었습니다.

**문제 상황**
- 기본 폰트 크기로는 노인 사용자가 읽기 어려움
- 버튼이 작거나 기능이 많으면 조작 실수가 잦음
- 의학 용어가 그대로 표시되면 이해하기 어려움

**해결 방법**
- 전체 폰트 크기를 기본 대비 1.5배 이상으로 확대 적용
- 핵심 기능만 메인 화면에 배치, 단계별 화면 흐름으로 단순화
- OpenAI API를 활용해 의학 용어를 쉬운 말로 자동 변환하여 안내
- 명확한 색상 대비(고대비 모드)로 시인성 강화

---

### 🔐 API 키 보안

초기에 API 키가 코드에 직접 포함될 위험이 있었습니다.

**문제 상황**
- 팀원 간 코드 공유 과정에서 API 키가 코드에 하드코딩될 위험
- GitHub에 실수로 키가 업로드될 경우 보안 사고 발생 가능
- 팀원마다 다른 API 키를 사용해야 하는 환경 차이 문제

**해결 방법**
- `.env` 파일로 API 키를 분리하고 `.gitignore`에 등록해 GitHub 업로드 차단
- `.env.example` 파일을 제공해 팀원이 키 형식을 쉽게 파악하도록 안내
- GitHub Actions Secrets를 활용해 배포 환경에서도 키가 노출되지 않도록 설정

- [ ] OCR 모델 고도화 (약봉투 특화 파인튜닝)

- [ ] 복약 알림 푸시 알림 기능
- [ ] 보호자 앱 연동 강화
- [ ] 오프라인 모드 지원 (경량 OCR 모델 탑재)
- [ ] 영문·외국어 약봉투 인식 지원
