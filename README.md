## 1. 개요

약봉투나 처방전 사진을 OCR로 인식하고,
복용 중인 약과 새 약을 비교해 부작용과 주의사항을 알려 주는 서비스입니다.

**참고 서비스: 아이약** (제안: 장보윤)
- 처방전·약봉투 촬영 인식, 복용 약 안전성 확인, 약 알람 및 기록
- **우리 서비스의 차별점**
  - 노인 사용자 중심의 큰 글자·단순 화면
  - 보호자(가족) 공유 기능
  - AI 기반 자연어 복약 안내

## 2. 프로젝트 배경

### 📊 왜 이 문제가 중요한가

> 우리나라 65세 이상 노인의 **89%** 가 1개 이상의 만성질환을 보유하고 있으며,
> 평균 **5.1개**의 약을 동시에 복용합니다.
> 여러 약을 함께 복용할 때 발생하는 **약물 부작용·상호작용**은
> 노인 응급실 입원의 주요 원인 중 하나입니다.
>
> 출처: 건강보험심사평가원, 노인 의약품 적정성 평가 보고서

| 통계 | 수치 |
|---|---|
| 65세 이상 만성질환 보유율 | 89% |
| 노인 1인 평균 복용 약 수 | 5.1개 |
| 약물 부작용으로 인한 노인 입원 비율 | 전체 입원의 약 10~20% |
| 복약 지시 미준수율 (노인) | 약 50% |

### 😔 실제 문제 상황

병원에서 처방받은 약봉투를 받았을 때
→ 약 이름이 어렵고 글씨가 작아 읽기 어렵습니다
→ 이미 먹고 있는 약과 함께 먹어도 되는지 알 수 없습니다
→ 자녀·보호자가 멀리 있어 바로 물어보기 어렵습니다
→ 약사에게 다시 물어보기 어렵거나 민망할 수 있습니다

### 💡 우리의 해결 방법

팀 회의(디스코드)에서 도출한 핵심 아이디어입니다.

> 💬 **장보윤**: "약봉지를 OCR로 분석해서 받아들인 정보를 한번 확인해서 저장되게끔 하는게 좋을 것 같아요"
> 💬 **이채리**: "추가하면 좋을 것 같은 기능: 큰 글자 기능, 가족과 공유 기능"
> 💬 **이채리**: "기존에 복용 중인 약이 있으면 기초 데이터로 저장"
> 💬 **장보윤**: "타겟층이 노년층인거죠"

**핵심 가치**

📸 찍으면 → 🤖 AI가 읽고 → 💊 안전한지 확인 → 👨‍👩‍👧 가족과 공유

## 6. 실행 방법

### 1) 저장소 클론
git clone https://github.com/17lucky71/medicine-guide-ai.git
cd medicine-guide-ai

### 2) 환경변수 설정
cp .env.example .env

OPENAI_API_KEY=your_openai_api_key_here
OCR_API_KEY=your_ocr_api_key_here
DATABASE_URL=sqlite:///./medicine.db


### 3) 백엔드 실행
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

### 4) 프론트엔드 실행
cd frontend
npm install
npm run dev

## 8. 기술적 도전과제

### 🔍 OCR 정확도 문제
약봉투는 글씨가 작고 배경이 복잡해 OCR 인식률이 낮았습니다.
- 이미지 전처리(그레이스케일, 이진화)로 인식률을 개선했습니다.
- 사용자가 인식 결과를 직접 수정할 수 있는 UI를 추가했습니다.

### 💊 약물 정보 매칭 문제
OCR로 인식한 약 이름이 DB의 약 이름과 정확히 일치하지 않는 경우가 많았습니다.
- 유사도 기반 검색(퍼지 매칭)을 도입해 해결했습니다.

### 👴 노인 친화적 UI 설계
일반적인 UI는 노인 사용자에게 복잡하게 느껴질 수 있었습니다.
- 큰 글자, 단순한 버튼 구성, 명확한 색상 대비를 적용했습니다.

### 🔐 API 키 보안
초기에 API 키가 코드에 직접 포함될 위험이 있었습니다.
- .env 파일과 .gitignore 설정으로 보안을 강화했습니다.

## 9. 한계점 및 향후 개선

### 현재 한계점
- OCR 정확도가 이미지 품질에 따라 달라질 수 있음
- 일부 약 정보는 데이터베이스에 없을 수 있음
- AI 설명이 실제 의료 판단을 완전히 대체할 수 없음

### 향후 개선 방향
- [ ] OCR 모델 고도화 (약봉투 특화 학습)
- [ ] 공공 약물 데이터베이스 연동 확대
- [ ] 음성 안내 기능 추가 (TTS)
- [ ] 복약 알림 푸시 알림 기능
- [ ] 보호자 앱 연동 강화
